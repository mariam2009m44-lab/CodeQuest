لعبة تخمين الرقم

لعبة ممتعة، الكمبيوتر بيفكر في رقم سري، وإنت بتحاول تخمنه. هتستخدم المتغيرات، الشروط، والحلقات.

import random secret = random.randint(1, 10) guess = 0 while guess != secret: guess = int(input("خمن الرقم من 1 لـ 10: ")) if guess < secret: print("أكبر!") elif guess > secret: print("أصغر!") print("عاش! خمنت صح")

الآلة الحاسبة

برنامج بياخد رقمين من المستخدم، وبيعمل عليهم عملية حسابية (جمع، طرح، ضرب، قسمة).

num1 = float(input("الرقم الأول: ")) num2 = float(input("الرقم الثاني: ")) op = input("العملية (+,-,*,/): ") if op == '+': print(num1 + num2) elif op == '-': print(num1 - num2) elif op == '*': print(num1 * num2) elif op == '/': print(num1 / num2)

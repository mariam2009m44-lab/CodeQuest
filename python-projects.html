لعبة تخمين الرقم

الكمبيوتر يختار رقمًا سريًا، وأنت تحاول تخمينه. المشروع يدرّبك على المتغيرات والشروط والحلقات.

import random

secret = random.randint(1, 10)
guess = 0

while guess != secret:
    guess = int(input("Guess 1 to 10: "))
    if guess < secret:
        print("Higher!")
    elif guess > secret:
        print("Lower!")

print("Correct!")

الآلة الحاسبة

برنامج يستقبل رقمين وعملية حسابية، ثم يعرض الناتج. جرّب إضافة معالجة للقسمة على صفر.

num1 = float(input("First number: "))
num2 = float(input("Second number: "))
op = input("Operation (+,-,*,/): ")

if op == "+":
    print(num1 + num2)
elif op == "-":
    print(num1 - num2)
elif op == "*":
    print(num1 * num2)
elif op == "/":
    if num2 != 0:
        print(num1 / num2)
    else:
        print("Cannot divide by zero")

قائمة المهام

أضف مهامًا إلى قائمة، واكتب «خروج» عند الانتهاء. جرّب بعد ذلك إضافة ميزة لحذف مهمة.

tasks = []

while True:
    task = input("Add task (or exit): ")
    if task == "exit":
        break
    if task.strip():
        tasks.append(task)

print("\\nYour tasks:")
for task in tasks:
    print("- " + task)

# CodeQuest Control Center — Django Admin

لوحة إدارة داخلية مستقلة لإدارة المحتوى التعليمي في CodeQuest. هذه المرحلة تطوّر أساس Django Admin ونماذج المحتوى فقط؛ لا تستبدل الواجهة الحالية أو FastAPI أو Firebase.

## ما أُضيف

- إدارة المسارات والمناهج والدروس مع تحرير العناصر التابعة من الصفحة نفسها.
- بنك أسئلة مرتبط بالدروس، مع التحقق من وجود اختيارين على الأقل وصحة مؤشر الإجابة.
- إدارة الإعلانات مع التحقق من أن تاريخ الانتهاء يأتي بعد تاريخ البداية.
- إدارة المشاريع التعليمية.
- إجراءات جماعية لنشر العناصر المحددة أو أرشفتها.
- بحث وفلاتر وترتيب وعرض صفحات منظم داخل لوحة الإدارة.
- واجهة Django Admin باللغة العربية.
- اختبارات لصلاحيات الدخول والتحقق من صحة المحتوى.

## تشغيل محلي

يتطلب Python 3.11 أو أحدث.

```bash
cd admin-portal
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS / Linux:
source .venv/bin/activate
pip install -r requirements.txt
python manage.py check
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

افتح `http://127.0.0.1:8000/admin/` وسجّل الدخول بحساب Staff/Superuser.

## الاختبارات

```bash
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
```

## الأمان

- لوحة الإدارة محمية بنظام Django Authentication وتتطلب مستخدمًا بصلاحية staff.
- لا يوجد تسجيل عام للمديرين.
- عيّن `DJANGO_SECRET_KEY` قويًا وسريًا في بيئة الاستضافة.
- اترك `DJANGO_DEBUG=false` في الإنتاج واضبط `DJANGO_ALLOWED_HOSTS` على نطاق لوحة الإدارة فقط.
- استخدم HTTPS وقاعدة بيانات دائمة ونسخًا احتياطية قبل تشغيلها لمستخدمين حقيقيين.
- لا تضع مفاتيح Firebase أو Gemini أو بيانات حسابات الطلاب في هذا التطبيق.

## حدود التكامل الحالية

هذه اللوحة لا تزال منفصلة عن واجهة CodeQuest المنشورة. لا تُنشر على GitHub Pages؛ Pages يستضيف ملفات ثابتة ولا يشغّل تطبيق Django/Python. يلزم خادم Python مستقل وقاعدة بيانات إنتاجية دائمة قبل الاستخدام الفعلي.

لا تقوم هذه النسخة بكتابة أي بيانات إلى Firestore، ولا يعني تغيير المحتوى هنا أنه تغيّر في المناهج المنشورة. كما أن إدارة حسابات الطلاب وبياناتهم ومكافآتهم عبر Django لم تُفعّل بعد. يجب تنفيذ تكامل خادمي موثق ومختبر مع Firebase Admin SDK أو واجهة آمنة محددة، مع صلاحيات محدودة وسجل تدقيق، قبل إتاحة هذه العمليات.

تظل Firebase/Firestore مصدر بيانات الطلاب والتقدم وXP والنجوم في الوقت الحالي. لا يتم نقل هذه البيانات إلى قاعدة Django.

## نشر الإنتاج

لا تنشر هذه المرحلة تلقائيًا. قبل النشر يلزم اختيار خدمة استضافة Python وقاعدة PostgreSQL دائمة، وضبط الأسرار والنطاق وHTTPS والنسخ الاحتياطية. لن يتم إنشاء خدمة مدفوعة أو الاشتراك فيها دون موافقة صريحة.
